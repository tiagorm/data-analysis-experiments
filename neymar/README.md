# Neymar

Experiments using GenAI to analyze Neymar's performance data and create a PDF with a storytelling about his convocation or not in the brazilian national soccer team.

Visual Studio as IDE. Code created mostly by Claude Sonnet 3.5 in Copilot, but also GPT-4.1.

## How to run

just ran `setup_and_run.bat` script, created for Windows environment, but not difficult to convert for a Linux one. It will create a Python virtual environment, install the requirements, and run both analysis scripts.
