# Neymar

Experiments using GenAI to analyze Neymar's performance data and create a PDF writing a story to support his convocation or not for the Brazilian national soccer team.

Visual Studio as IDE. Code created mostly by Claude Sonnet 3.5 in Copilot, but also GPT-4.1.

Data utilized: https://github.com/LunusMax/football-data/tree/main/Neymar

## How to run

You just need to run `setup_and_run.bat` script, created for Windows environment, but not so difficult to convert to a Linux one. It will create a Python virtual environment, install the requirements, and run both analysis scripts.
